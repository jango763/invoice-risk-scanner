✦ Invoice Risk Scanner v0.1 · браузерный прототип

Проверка инвойса на санкционные риски

Извлечение реквизитов и кодов ТН ВЭД/HS, поиск совпадений в загруженных вами перечнях, объяснение результатов. Содержимое документа обрабатывается в браузере, без отправки на наш сервер.

1. Загрузите инвойс

PDF · XLSX · CSV · TXT · фото

Файл не выбран

Приватность: файл не загружается на сервер этого инструмента. Для PDF, Excel и OCR используются библиотеки из CDN, которые загружаются через интернет. OCR выполняется локально. Не используйте реальные банковские документы без согласования с ИБ и комплаенсом.

2. Подключите перечни для проверки

Прототип не содержит актуальных санкционных баз «из коробки». Чтобы увидеть совпадения, загрузите таблицы в формате CSV. Дата актуальности и юридическая применимость перечней проверяются отдельно.

Не загружен
Не загружен

Для лиц: name;aliases;source;reference. Для товаров: code;source;notes. Формат учебный; официальные XML/CSV поставщиков обычно требуют адаптера и привязки к редакции нормативного акта.

Демо-перечни вымышленные и не отражают санкции.

3. Результат предварительного анализа

Проверка ещё не выполнена. Без актуальных санкционных списков программа не может подтверждать отсутствие ограничений.

Принципы результата


Совпадение Найдено точное или похожее название либо код в загруженном списке. Требуется ручная проверка.


Требует проверки Нет ключевой информации или нужного источника.


Не установлено Прототип не может определить применимость нормы по одному инвойсу.


Автоматического юридического вывода «санкционный / несанкционный» в версии 0.1 нет. Программа не принимает решений о проведении платежа.
