# Invoice Risk Scanner — v0.1

Браузерный прототип для **предварительного** анализа инвойсов на санкционные и товарные риски.

## Запуск

Откройте `index.html` в современном браузере. Сборка и сервер приложения не требуются.

После включения GitHub Pages программа доступна по адресу:
https://jango763.github.io/invoice-risk-scanner/

### Публикация на GitHub Pages

1. Откройте Settings → Pages в этом репозитории.
2. В Source выберите **Deploy from a branch**.
3. В Branch выберите **main**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь завершения публикации. Последующие изменения в `main` будут публиковаться автоматически.

### Первый запуск

1. Откройте программу и загрузите инвойс или выберите учебный пример.
2. При необходимости загрузите CSV-перечни участников и товарных кодов.
3. Запустите анализ и проверьте найденные реквизиты, совпадения и задачи для ручной проверки.
4. Сохраните отчёт в JSON.

Для PDF, Excel и OCR нужен интернет: библиотеки и языковые модели загружаются при использовании соответствующего формата.

## Что реализовано

- Загрузка PDF, изображений, Excel, TXT и CSV до 15 МБ;
- Извлечение текста и OCR (для сканов / фото);
- Поиск номера инвойса, сторон сделки, товарных кодов, стран и валют;
- Поиск возможных совпадений с отдельно загружаемыми CSV-списками участников и товарных кодов;
- Демонстрационный инвойс и вымышленные тестовые перечни;
- Предварительный отчёт в JSON.

## Важные ограничения

- Программа **не подключена к актуальным официальным санкционным реестрам** и не доказывает отсутствие санкционных рисков.
- Совпадение имени или кода требует проверки: применимость норм зависит от юрисдикции, маршрута, собственников, характера товара, конечного использования и иных обстоятельств.
- Программа не должна автоматически разрешать банковские платежи или заменять решение специалиста по комплаенсу.
- Инвойс обрабатывается в браузере без отправки на сервер данного приложения; библиотеки PDF, Excel и OCR загружаются через сторонние CDN. Для использования с конфиденциальными данными требуется проверка ИБ.
- Реальные банковские инвойсы не следует загружать без внутренних разрешений и проверок.

## Структура

- `index.html` — автономная одностраничная программа (зависимости OCR/PDF/Excel загружаются через CDN).
- `README.md` — инструкция и ограничения.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.
- `.gitignore` — исключение локальных служебных файлов.
